# AI City Simulator

A real-time interactive city simulation with AI agents, dynamic systems, and a visual interface.

## Features

- **Interactive City Map**: Visualize a dynamic city with various locations
- **AI Agents**: Autonomous agents with personalities, goals, and daily routines
- **Dynamic Systems**: Crime, traffic, weather, and emergent behaviors
- **Real-time Visualization**: Interactive GUI with filtering, zooming, and time controls

## Locations

- **Residential**: Apartments, houses, senior living facilities
- **Commercial**: Gyms, grocery stores, restaurants, coffee shops, bars
- **Educational**: Elementary schools, high schools, colleges
- **Transportation**: Airport, bus stops, bus routes
- **Public Services**: Police stations, hospitals, parks

## Agent Types

- Residents
- Workers
- Students
- Law Enforcement
- Criminals
- Visitors

## Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/ai_city_simulator.git
cd ai_city_simulator

# Install dependencies
pip install -r requirements.txt
```

## Running the Simulation

```bash
python src/main.py
```

## Controls

- **Mouse Wheel**: Zoom in/out
- **Left Click + Drag**: Pan the map
- **Right Click on Agent**: View agent details
- **Space**: Pause/Resume simulation
- **+/-**: Speed up/slow down simulation
- **F**: Toggle fullscreen
- **ESC**: Exit

## Customization

You can customize the simulation by editing the configuration files in the `config` directory.
